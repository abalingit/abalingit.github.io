AndroidBLEKotlinEven G2

G2 Companion Apps

Both shipped to abalingit/g2-android-control and abalingit/media-control on GitHub.

MCPWorkersAgents SDK

G2 Bridge & MCP Integrations

Cloudflare Worker that routes G2 glasses voice commands to the OpenClaw agent pipeline (with markdown cleanup, auth, health checks), plus MCP servers that give local agent runtimes access to internal tools and services. The G2 bridge is live at g2.omghi.lol behind a Cloudflare tunnel.

n8nWhisperMemos

Voice → Second Brain Pipeline

Voice notes transcribed via a local faster-whisper endpoint, routed through n8n workflows, and stored in a self-hosted Memos instance. The result: a searchable personal knowledge base I can add to hands-free — driving, cooking, or walking the dog.

n8nNetWatchPi-hole

NetWatch Network Monitoring

n8n pipeline that collects metrics from a Pi-hole DNS server and NetWatch (Raspberry Pi 5) every 6 hours, cross-references with NetData on the Unraid host, and sends anomaly alerts to Telegram. Includes a custom Python collector that feeds Pi-hole stats into NetData's charting engine.

Node.jsMCPHome Assistant

HA Proxy — MCP Cold-Start Fix

Home Assistant's MCP integration had ~2-minute cold starts on model context queries. Built a persistent Node.js HTTP proxy (port 9876) that keeps the HA connection warm and responds in ~40ms. Includes a CLI wrapper, watchdog script, and stdin client for ergonomic use.
